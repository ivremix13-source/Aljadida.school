المدرسة الجديدة النموذجية بنين — نموذج بوابة ويب
================================================

الملفات:
- index.html : بنية الصفحات والمكونات.
- style.css  : التصميم المتجاوب.
- app.js     : التنقل والتسجيل التجريبي ورفع ملفات PDF محليًا.
- logo.png   : ضع شعار المدرسة بهذا الاسم في المجلد نفسه عند استلامه.

التشغيل:
1. افتح المجلد في Visual Studio Code.
2. شغّل index.html باستخدام إضافة Live Server، ثم افتح الرابط المحلي الذي توفره الإضافة.
3. من أسفل الصفحة افتح "إدارة المحتوى التجريبية".
4. عدّل أسماء المقررات، اختر ملفات PDF (حتى 25 ميجابايت لكل ملف)، ثم اضغط "حفظ المقرر والملف".
5. طلبات التسجيل والملفات محفوظة محليًا في المتصفح الذي رفعها فقط.

مهم قبل النشر الحقيقي:
هذه نسخة واجهة أولية للتجربة، وليست نظام إدارة مدرسي آمنًا متعدد المستخدمين. لا توجد قاعدة بيانات خادمية أو حسابات إدارة محمية. لا تظهر الملفات المرفوعة على أجهزة الطلاب الأخرى. لا تنشرها كما هي لاستقبال بيانات طلاب حقيقية. يلزم ربطها بخادم أو Firebase مع قواعد صلاحيات مناسبة، وتخزين ملفات في خدمة تخزين، والتحقق من صلاحيات الإدارة على الخادم.

الشعار:
ضع صورة الشعار باسم logo.png داخل هذا المجلد. ستظهر تلقائيًا في شاشة التحميل ورأس الصفحة والواجهة الرئيسية وصفحة الدخول والتذييل.
