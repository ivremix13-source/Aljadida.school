المدرسة الجديدة الثانوية النموذجية بنين — دليل تشغيل مختصر

الملفات:
- index.html : هيكل الصفحات والمحتوى.
- style.css  : جميع الألوان والتنسيقات والحركات والتصميم المتجاوب.
- app.js     : التنقل بين الصفحات، وفهرس الكتب، وأرقام التواصل.
- assets/    : ضع شعار المدرسة هنا.

إضافة شعار المدرسة:
1) أنشئ صورة للشعار بصيغة PNG (يفضل خلفية شفافة).
2) ضعها داخل مجلد assets باسم school-logo.png.
3) لا تحتاج إلى تعديل الكود؛ سيظهر الشعار تلقائياً في شاشة البداية والترويسة والتذييل.

إضافة روابط ملفات الكتب:
1) افتح app.js.
2) ابحث عن المصفوفة BOOKS.
3) غيّر url: '' إلى رابط ملف PDF الفعلي لكل كتاب، مثل url: 'books/math.pdf' إذا وضعت الملف داخل مجلد books.
4) عند توفر الرابط سيتحول الزر إلى «فتح الكتاب» تلقائياً.

إضافة أرقام التواصل:
1) افتح app.js وابحث عن CONTACT_ITEMS.
2) ضع الرقم أو البريد في الخاصية value.
3) الأنواع المدعومة: phone، whatsapp، email، location، website.

إضافة قسم جديد:
- أضف رابطاً داخل main-nav باستخدام href="#اسم-القسم" و data-nav.
- أضف section جديدة داخل main تحمل data-page="اسم-القسم" ومعرّف id="page-اسم-القسم".
- أضف اسم القسم إلى مصفوفة PAGE_NAMES في app.js.
- صمّم محتوى الصفحة باستخدام أصناف style.css الموجودة أو أضف أصنافاً جديدة.

التشغيل:
افتح index.html في المتصفح أو افتح مجلد المشروع في Visual Studio Code واستخدم إضافة Live Server.
يتطلب تحميل خط Cairo وأيقونات Font Awesome اتصالاً بالإنترنت. صُممت الواجهة نفسها لتظل قابلة للتصفح عند تعذّر تحميلهما.

مهم:
هذه نسخة واجهة أمامية فقط؛ لا تحتوي على لوحة إدارة أو قاعدة بيانات. روابط الكتب وبيانات التواصل غير مُضافة افتراضياً حتى تضع البيانات الحقيقية بنفسك.
